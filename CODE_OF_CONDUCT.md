# Code of Conduct

We are committed to a respectful, harassment-free community. Be constructive,
assume good intent while evaluating claims critically, and focus technical
disagreement on evidence and reproducible behavior.

Unacceptable behavior includes harassment, discrimination, threats, publishing
private information, deliberate disruption, and bad-faith security disclosures.
Maintainers may edit, reject, or remove contributions and participation that
violate these expectations. Report conduct concerns privately to the repository
maintainers. Security vulnerabilities should follow `SECURITY.md`.
